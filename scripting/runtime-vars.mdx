---
title: Runtime Variables
description: "Read details about the current user, such as their Discord ID and total executions, from your script"
---

Luarmor provides runtime variables that give your script details about the current user, such as their Discord ID, total executions, premium status and note, as well as the script name.

<Warning>
    Luarmor does not protect these runtime variables, so they can be hooked and modified maliciously.
    Add your own protections if needed.

    They are also never updated while your script runs.
    You need to track changes to variables like `LRM_SecondsLeft` **yourself**.
</Warning>

For values that can't be spoofed, use [server-side webhook variables](/features/webhook-protection#server-side-variables) or the [Key Check Library](/scripting/key-check-library).

Here's an example of what you can do with them:

```lua
print(LRM_ScriptName .. " has been loaded successfully!")
print("Your discord ID is: " .. LRM_LinkedDiscordID)
print("and you executed this script " .. LRM_TotalExecutions .. " in total")
print("Your access will end in " .. LRM_SecondsLeft / 86400 .. " days")

if LRM_IsUserPremium then
    warn("You have premium access. Loading secret admin GUI!")
    freemium_LoadAdmin()
else
    warn("You are using the free version.")
end

if string.find(LRM_UserNote, "beta") then
    warn("You have beta access. Loading beta GUI")
    LoadBetaGUI()
end
```

## All runtime variables

| Variable | Description |
| --- | --- |
| `LRM_IsUserPremium` | A `boolean` indicating whether the user is whitelisted (premium) or not. This is useful for Free for All (FFA) scripts with premium features ("freemium"). |
| `LRM_LinkedDiscordID` | The linked Discord ID of the user. |
| `LRM_ScriptName` | The name of the current script. |
| `LRM_TotalExecutions` | The user's total number of executions. It is `0` by default. |
| `LRM_SecondsLeft` | The number of seconds until the key expires. It is `math.huge` if `auth_expire` isn't set. |
| `LRM_UserNote` | The user's note. It is `Not specified` by default. |
| `LRM_ScriptVersion` | The version of the script as a `string`, e.g. `"0.0.0.3"`. |
