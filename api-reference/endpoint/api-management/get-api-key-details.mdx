---
title: Get API Key Details
description: "Retrieve details about your API key: your account, plus every project and script linked to it (project and script IDs, script names, versions and settings)."
---

## Endpoint

`GET https://api.luarmor.net/v3/keys/{api_key}/details`

Example URL: `https://api.luarmor.net/v3/keys/300058fb1987f0e019b0c980ad01/details`

## Path parameters

| Name      | Type   | Required | Description                   |
|-----------|--------|----------|-------------------------------|
| `api_key` | string | Yes      | The API key to get details for |

## Error responses

| Status | Meaning                          |
|--------|----------------------------------|
| `400`  | The API key is wrong.            |
| `403`  | The API key is no longer valid.  |

Example `400` response:

```json
{
	"success": false,
	"message": "Wrong API key"
}
```

Example `403` response:

```json
{
	"success": false,
	"message": "Invalid API key! Visit https://luarmor.net/ to get access."
}
```

## Example request

```bash
curl -H "Authorization: <api_key>" \
		 https://api.luarmor.net/v3/keys/<api_key>/details
```
