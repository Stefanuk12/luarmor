This page shows you how to check whether a Discord server really offers what you are paying for.

<Note>
    You can find a [list of currently active scam servers](#known-scam-servers) at the bottom of this page.
</Note>

## Hints

<Warning>
    - If a seller offers unbelievably good features for a popular game, such as "rollback", "dupe" or "infinite something", be extra cautious before buying.
    - If the seller claims to have a *"buyers only"* server that you will be invited to after purchase, this should raise a **red flag**, especially if their public server is read-only and **no one can send a message**.
    - If the seller only accepts non-refundable payment methods such as crypto, gift cards or in-game items, this should raise a **red flag**.
    - A "verified by Luarmor" card is **not** proof that a seller is legit. [Verified scripts](/scripting/verification) have been discontinued, and being verified only ever meant the script was free of malware.
</Warning>

## Steps to identify

If a seller claims to use Luarmor, you might assume that they are legitimate. However, this is not always the case. Anyone can purchase a Luarmor API key and invite the bot to their server.

We take down scam servers when they are reported, but some go unnoticed because no one reports them. (See [how to report a scam server](#how-to-report-a-scam-server).)

<Steps>
    <Step title="Check if the Discord bot is really in the server">
        Here is an example:

        <Frame caption='Known scam server "Glacier X" - Server ID: 1140429912369537148'>
            ![Glacier X script-panel channel annotated: the seller claims the bot is in a "buyers only" server, the panel is only a screenshot, and the messages are inconsistent](/images/common-scams-glacier-x-buyer-server.png)
        </Frame>

        There is **no reason** for a seller to have a "buyers only" server. Luarmor already has a [buyer role system](/discord-bot#buyer-role) that lets sellers separate buyers and non-buyers within a single Discord server.

        You may also notice that the **Discord bot** is not in the server at all. This should be a massive red flag for any buyer.

        Here is another example:

        <Frame caption='Scam server "Project Zero" - Server ID: 1072525328318214144'>
            ![Project Zero get-script channel where the Luarmor panel says "This interaction failed" and the bot has no mutual servers](/images/common-scams-project-zero-bot-missing.png)
        </Frame>

        The Discord bot was invited at some point but is no longer in the server, and the seller is making false claims about it. This should convince you to leave the server immediately.
    </Step>

    <Step title="Verify the Discord bot is real">
        <Info>
            Currently active Luarmor bots can be found at [https://luarmor.net/bot](https://luarmor.net/bot).
        </Info>

        If the Discord bot is **in the server** and seems to be responsive, open its profile, click the **⋮** menu next to **Message** and choose **Copy User ID**. Then compare it to the IDs on the official bot page linked above. Both the username (e.g. `Luarmor#3309`) and the ID must match the same entry.

        <Frame caption="A bot that might be real">
            ![Luarmor bot profile with the Copy User ID option highlighted](/images/common-scams-copy-bot-user-id.png)
        </Frame>

        <Frame caption="https://luarmor.net/bot">
            ![Official bot invite list on luarmor.net/bot with the username Luarmor#3309 and ID 1134118860119887882 highlighted as matching](/images/common-scams-official-bot-ids.png)
        </Frame>

        Official bots at the time of the screenshot (always check [luarmor.net/bot](https://luarmor.net/bot) for the current list):

        | Bot | Username | User ID |
        | --- | --- | --- |
        | Bot 7 (latest) | `Luarmor#6199` | `1267908035632959590` |
        | Bot 6 | `Luarmor#7175` | `1252444857977536602` |
        | Bot 5 | `Luarmor#2977` | `1232775347037012068` |
        | Bot 4 | `Luarmor#5671` | `1214516393186168852` |
        | Bot 3 | `Luarmor#3309` | `1134118860119887882` |
        | Bot 2 | `Luarmor#4108` | See [luarmor.net/bot](https://luarmor.net/bot) |
        | Bot 1 | `Luarmor#1476` | `1150311440352292876` |

        If everything seems to be consistent, you can proceed to the next step.
    </Step>

    <Step title="Read what others said about it">
        If the server has a `#vouches` channel, check what is posted there.

        <Warning>
            If all of the vouches are screenshots posted by the same few people, this should raise another massive **red flag**. There is **no way to verify if a screenshot is real.** Anyone can edit or fake one.
        </Warning>

        Here are two examples of bad vouch channels:

        ![Project Zero vouches channel made up entirely of screenshots posted by the server owner](/images/common-scams-vouches-project-zero.png)

        ![Glacier X buyer-feedback channel with screenshot-only vouches and fake-looking keys annotated](/images/common-scams-vouches-glacier-x.png)

        In both channels, every screenshot was posted by the same 1-2 accounts, which belong to the server owners, so there is no way to know whether the vouches are real.

        Even if vouches are posted by different accounts, check whether each account belongs to a real person (for example, a booster badge, an old join date, activity in other communities, or mutual servers).
    </Step>
</Steps>

### Still not sure?

You can create a ticket in the `#support` category in our Discord server ([discord.gg/luarmor](https://discord.gg/luarmor)) and ask whether a seller is legitimate. Include the seller's Discord server invite in the ticket (for example, `gg/jCHkq`).

![Support ticket form asking whether a seller is legit, including their Discord invite](/images/common-scams-support-ticket-form.png)

In the ticket form, fill in:

| Field | What to write |
| --- | --- |
| What is this ticket about? | e.g. "I want to know if this seller is legit" |
| What are you running? | The seller's Discord invite, what they claim to sell, and that they say they use Luarmor |

## How to report a scam server?

You can create a support ticket in our Discord ([discord.gg/luarmor](https://discord.gg/luarmor)) and send all the evidence you have.

Please note that we are very skeptical about these reports and will **ignore your submission** if any of the information seems inconsistent to staff.

<Warning>
    Failure to provide enough proof will result in your ticket being closed without any further investigation, and possibly a ban.
    It's **very** important that you provide as much information as possible when opening the ticket, instead of us having to ask you for it.
</Warning>

Unfortunately, if you have been scammed, our support staff may not be able to help, and we are unlikely to be able to investigate much.
However, if you open a ticket with **full** details, we may be able to help.

<Info>
    Required details for a scam report:

    - Valid server invite (send as `gg/abcdefg`).
    - Screenshots of all channels in the server (especially `#vouches`, `#panel`, `#get-script` etc.).
    - Server ID and owner IDs.
    - The scammer's username.
    - Proof of any payment you made, with screenshots of tickets / DMs. If you are banned from the server, send us the payment receipt or any proof of payment that clearly shows it was for that script.
    - Proof that you did not receive what you paid for.
    - Any other relevant information that can strengthen your case.

    We will evaluate these details and **if they are using Luarmor**, we will take the necessary action. If they are not using Luarmor, there isn't much we can do.
</Info>
